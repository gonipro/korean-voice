# korean-voice · 한국어 문체 점수 · AI 티 지우개

사용자 글 5~10편으로 **그 사람만의 문체 기준(my-voice.json)**을 만들고, 새 글이 그 기준과 얼마나 닮았는지(나다움), AI 같은지(AI 티)를 숫자로 보여 준 뒤, 고칠 문장을 사용자 말투로 다시 써 준다.

글은 사용자 컴퓨터 안에서만 처리한다. 인터넷이나 외부 서비스로 보내지 않는다.

## 1. 내 문체 기준 만들기 (처음 한 번)

1. 사용자에게 **평소 자기가 직접 쓴 글 5~10편**을 받는다(블로그, 스레드, 일기, 메일 등. 한 채널 글끼리 모으면 더 정확하다).
   - 받은 글은 `my-samples/` 폴더에 `01.txt`, `02.txt`처럼 저장한다.
   - AI가 대신 써 준 글, 남이 쓴 글은 빼 달라고 한다.
2. 이 스킬 폴더 기준으로 실행한다.
   ```
   node scripts/kv.mjs profile my-samples/*.txt > my-voice.json
   ```
3. 만들어진 기준을 사용자에게 쉬운 말로 설명한다.
   - 주로 쓰는 끝맺음(예: "~음·됨 58%, ~다 22%")
   - 평균 문장 길이와 짧은 문장 비율
   - 1인칭(나·내가·저는)이 얼마나 나오는지
   - 평소 AI 같은 표현이 거의 없는지

## 2. 새 글 채점하기

```
node scripts/kv.mjs score my-voice.json 새글.txt
```

- **나다움 0~100:** 높을수록 평소 내 글과 닮았다.
- **AI 티 0~100:** 낮을수록 사람 글 같다. "다양한", "효과적으로", "결론적으로", "해 보세요" 같은 말이 몰리거나 문장 길이가 너무 고르면 올라간다.
- **고쳐 보면 좋은 문장:** 번호와 이유가 같이 나온다.

결과를 사용자에게 보여 줄 때는 점수 두 개와 고칠 문장만 짧게 보여 준다.

## 3. 내 말투로 고쳐 쓰기

짚힌 문장을 고칠 때 지킬 것:

- `my-voice.json`의 **가장 많이 쓰는 끝맺음**으로 맞춘다. 예: 기준이 "~음·됨"이면 "중요합니다" → "중요함".
- **평균 문장 길이**에 맞게 자른다. 긴 문장은 둘로 나누고, 짧은 문장을 연달아 쓰는 사람이면 그 리듬을 살린다.
- 권유형("해 보세요", "추천드립니다"), "여러분", "결론적으로", "도움이 되셨기를" 같은 말은 사용자가 평소 안 쓰면 뺀다.
- 사용자가 직접 겪은 일처럼 쓰지 않는다. 겪지 않은 걸 1인칭 체험으로 지어내지 않는다.
- 고친 뒤 다시 `score`를 돌려서 나다움이 올랐는지, AI 티가 내려갔는지 보여 준다.

## 하지 않는 것

- 사용자 글을 다른 곳에 올리거나 보내지 않는다.
- 점수를 "반응이 좋을 글"로 설명하지 않는다. 이 점수는 **내 문체와 닮은 정도**일 뿐, 조회수나 댓글을 예측하지 않는다.
- 남의 문체를 흉내 내는 데 쓰지 않는다(본인 글로 만든 기준만 쓴다).
