# korean-voice · 한국어 문체 점수 · AI 티 지우개

내 글 5편이면 **내 문체 기준**이 생기고(쌓아 둔 글이 많을수록 더 정확해요),
새 글이 얼마나 **나다운지**, 얼마나 **AI 같은지** 숫자로 보여 줘요.
AI 같은 문장은 짚어서 **내 말투로** 고쳐 줘요.

> ### 개발 몰라도 돼요. 클로드에게 이렇게만 말하세요
> **"github.com/gonipro/korean-voice 이 스킬 설치하고, 내 글로 내 문체 기준 만들어 줘"**
>
> 5편부터 시작돼요. 블로그·스레드처럼 오래 써 온 글이 많다면 많이 넣을수록 내 말투를 더 정확하게 잡아요.

## 왜 만들었나

2007년부터 블로그에 글을 써 왔어요. 스포츠 기자로, 운동 크리에이터(삐랑뚱땅)로 20년 가까이요.
AI로 글을 쓰기 시작하니 다 비슷한 말투가 됐어요. "다양한", "효과적으로", "도움이 되셨기를".
그래서 비개발자인 제가 AI 팀이랑 직접 만들었어요. 한국어 글맛을 숫자로 재는 도구가 없어서요.

코드는 AI가 짜고, 맞는지 틀린지는 글 쓰는 사람이 봐요.
바이브코딩의 강점은 개발자끼리 모이는 게 아니라 **각 분야 전문가가 같이 만들 수 있다**는 거라고 생각해요.

— 고운 · [고니프로](https://gonipro.app)

## 무엇을 재나요 (첫 버전)

| 재는 것 | 예 |
|---|---|
| **종결 어미** | ~다 / ~음·됨·임 / ~요 / ~습니다 / 반말(~어·~지)을 얼마나 쓰는지 |
| **문장 길이 리듬** | 평균 길이, 들쭉날쭉한 정도, 짧은 문장 비율 |
| **권유형·AI 티 표현** | "해 보세요", "결론적으로", "다양한", "효과적으로", "도움이 되셨기를" 등 |
| **1인칭 체험** | 나·내가·저는 같은 말이 얼마나 나오는지 |

영어권 문체 도구는 많지만 한국어 끝맺음과 리듬을 재는 도구는 없어서 처음부터 한국어로 만들었어요.

## 예시

평소 내 글(가상 인물, `examples/samples`)로 기준을 만들고 두 글을 재 봤어요.

```
내 말투로 쓴 글                AI가 쓴 듯한 글
나다움 84점                    나다움 23점
AI 티 14점                     AI 티 81점
                               고쳐 보면 좋은 문장
                                 1. 주말에는 다양한 활동을 통해 효과적으로 휴식을 취하는 것이 중요합니다.
                                    → 다양한 · 효과적·효율적 · 중요합니다·핵심은
```

## 한국어 AI 티 표현 사전

이 저장소의 중심이에요. [`data/ai-tells.json`](data/ai-tells.json)에 AI 글에서 자주 보이는 한국어 표현이 예문, 이유와 함께 모여 있어요.

| 종류 | 예 |
|---|---|
| 말투 | 해 보세요 · 추천드립니다 · 알아보겠습니다 · ~것이 좋습니다 |
| 낱말 | 다양한 · 효과적으로 |
| 연결어 | 결론적으로 · 또한, · 이처럼 |
| 마무리 | 도움이 되셨기를 · 함께 만들어 가요 |

### 이런 분들이 같이 만들어요
AI 티를 제일 잘 알아보는 건 개발자가 아니라 **글을 다루는 사람**이에요.

| 분야 | 잘 보는 것 |
|---|---|
| 기자·편집자 | 보도자료체, 기사체에 묻은 AI 티 |
| 국어 교사 | 어색한 연결어, 문법은 맞는데 어색한 문장 |
| 번역가 | 번역투("~를 통해", "~에 있어서") |
| 카피라이터·마케터 | 광고 문구, 상세페이지에 묻은 AI 티 |
| 작가·블로거 | 감성 마무리, 구호 같은 끝맺음 |

**발견한 말이 있으면 [제보](../../issues/new/choose)해 주세요.** 개발 몰라도 칸 몇 개만 채우면 돼요. 사전에 **이름과 분야**를 같이 남겨 드려요. 자세한 건 [같이 만들기](CONTRIBUTING.md).

## 직접 돌려 보기 (개발자용)

노드(Node.js 18 이상)만 있으면 돼요. 설치할 것 없음, 인터넷 연결 없음. 글은 내 컴퓨터 밖으로 안 나가요.

```bash
# 1) 내 문체 기준 만들기 (내 글 5~10편)
node scripts/kv.mjs profile my-samples/*.txt > my-voice.json

# 2) 새 글 채점
node scripts/kv.mjs score my-voice.json 새글.txt

# 결과를 JSON으로
node scripts/kv.mjs score my-voice.json 새글.txt --json
```

예시로 바로 해 보기:

```bash
node scripts/kv.mjs profile examples/samples/*.txt > examples/my-voice.json
node scripts/kv.mjs score examples/my-voice.json examples/draft_ai.txt
```

## 클로드 코드 스킬로 쓰기

`skills/korean-voice/SKILL.md`가 클로드에게 주는 설명서예요.
클로드에게 저장소 주소를 주고 설치해 달라고 하면, 기준 만들기 → 채점 → 내 말투로 고쳐 쓰기까지 알아서 해요.

## 알아 둘 것

- 이 점수는 **내 문체와 닮은 정도**예요. 조회수나 댓글을 예측하지 않아요. 반응은 결국 "나한테 일어난 일"이 만들어요.
- 내 글로 만든 기준만 쓰세요. 남의 문체를 흉내 내는 용도가 아니에요.
- 같은 채널 글끼리(스레드는 스레드끼리, 블로그는 블로그끼리) 기준을 따로 만들면 더 정확해요.
